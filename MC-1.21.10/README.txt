===========================================
  INSTALACION - PASO A PASO
===========================================

IMPORTANTE: Sigue estos pasos EXACTAMENTE.

PASO 1: Instalar Fabric Loader
-------------------------------
1. Ve a https://fabricmc.net
2. Descarga Fabric Loader para MC 1.21.10
3. Ejecuta el instalador
4. Selecciona MC 1.21.10 y haz clic en "Install"
5. Abre el Minecraft Launcher
6. Deberias ver un perfil "fabric-loader-1.21.10"

PASO 2: Descargar este Modpack
--------------------------------
1. Haz clic en "Descargar" en la tabla de la pagina de GitHub
2. Extrae este archivo .zip usando WinRAR, 7-Zip o Windows (clic derecho > Extraer todo)
3. Veras una carpeta con:
   - mods/ (carpeta con archivos .jar)
   - options.txt (configuracion de video)
   - README.txt (este archivo)

PASO 3: Copiar MODS
--------------------
1. Abre la carpeta extraida "mods"
2. Selecciona TODOS los archivos .jar dentro
3. Copialos (Ctrl+C)
4. Navega a: %appdata%\.minecraft\mods\
   - Presiona Win+R, escribe: %appdata%\.minecraft\mods\
   - O ve a: C:\Users\[TU_USUARIO]\AppData\Roaming\.minecraft\mods\
5. Pega todos los archivos .jar aqui (Ctrl+V)
6. Si la carpeta no existe, creala manualmente

PASO 4: Copiar OPTIONS.TXT (Configuracion de Video)
-----------------------------------------------------
1. Copia el archivo "options.txt" de este modpack
2. Navega a: %appdata%\.minecraft\
3. Pega options.txt aqui (SOBREESCRIBIR si te lo pide)
4. Esto establece la distancia de renderizado a 8 chunks y otras optimizaciones

PASO 5: Iniciar Minecraft
---------------------------
1. Abre el Minecraft Launcher
2. Selecciona el perfil "fabric-loader-1.21.10"
3. Haz clic en "Play"
4. Espera a que los mods se carguen
5. Disfruta de +30-400% FPS!

===========================================
  SOLUCION DE PROBLEMAS
===========================================

PROBLEMA: "Incompatible mods found"
SOLUCION: Asegurate de usar la VERSION CORRECTA.
          Este modpack es solo para MC 1.21.10.

PROBLEMA: El juego falla al iniciar
SOLUCION: 1. Asegurate de tener Fabric Loader instalado
          2. Asegurate de copiar TODOS los archivos .jar
          3. Elimina la carpeta META-INF en .minecraft si existe
          4. Asigna 4GB de RAM a Minecraft

PROBLEMA: Como asignar mas RAM?
SOLUCION: 1. Minecraft Launcher > Instalaciones
          2. Haz clic en tu perfil de Fabric > Editar
          3. Mas Opciones > Argumentos JVM
          4. Cambia -Xmx2G por -Xmx4G

PROBLEMA: Los mods no se cargan
SOLUCION: 1. Asegurate de que los .jar esten en .minecraft\mods\
          2. NO en una subcarpeta dentro de mods/
          3. Reinicia Minecraft
