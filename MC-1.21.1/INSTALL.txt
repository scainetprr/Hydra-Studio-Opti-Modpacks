===========================================
  INSTALLATION - STEP BY STEP
===========================================

IMPORTANT: Follow these steps EXACTLY.

STEP 1: Install Fabric Loader
-----------------------------
1. Go to https://fabricmc.net
2. Download Fabric Loader for MC 1.21.1
3. Run the installer
4. Select MC 1.21.1 and click "Install"
5. Open Minecraft Launcher
6. You should see a "fabric-loader-1.21.1" profile

STEP 2: Extract this .rar file
-------------------------------
1. Right-click this .rar file
2. Select "Extract Here" or use WinRAR/7-Zip
3. You will see a folder with:
   - mods/ (folder with .jar files)
   - options.txt (video settings)
   - README.txt (this file)

STEP 3: Copy MODS
------------------
1. Open the extracted "mods" folder
2. Select ALL .jar files inside
3. Copy them (Ctrl+C)
4. Navigate to: %appdata%\.minecraft\mods\
   - Press Win+R, type: %appdata%\.minecraft\mods\
   - Or go to: C:\Users\[YOUR_USER]\AppData\Roaming\.minecraft\mods\
5. Paste all .jar files here (Ctrl+V)
6. If folder doesn't exist, create it manually

STEP 4: Copy OPTIONS.TXT (Video Settings)
-------------------------------------------
1. Copy the "options.txt" file from this modpack
2. Navigate to: %appdata%\.minecraft\
3. Paste options.txt here (OVERWRITE if asked)
4. This sets render distance to 8 chunks and other optimizations

STEP 5: Launch Minecraft
-------------------------
1. Open Minecraft Launcher
2. Select the "fabric-loader-1.21.1" profile
3. Click "Play"
4. Wait for mods to load
5. Enjoy +30-400% FPS!

===========================================
  TROUBLESHOOTING
===========================================

PROBLEM: "Incompatible mods found"
SOLUTION: Make sure you're using the CORRECT version.
          This modpack is for MC 1.21.1 only.

PROBLEM: Game crashes on startup
SOLUTION: 1. Make sure Fabric Loader is installed
          2. Make sure you copied ALL .jar files
          3. Delete META-INF folder in .minecraft if exists
          4. Allocate 4GB RAM to Minecraft

PROBLEM: How to allocate more RAM?
SOLUTION: 1. Minecraft Launcher > Installations
          2. Click on your Fabric profile > Edit
          3. More Options > JVM Arguments
          4. Change -Xmx2G to -Xmx4G

PROBLEM: Mods not loading
SOLUTION: 1. Make sure .jar files are in .minecraft\mods\
          2. NOT in a subfolder inside mods/
          3. Restart Minecraft
